# Videos Repository

This repository contains MP4 video files used for Blogger video sliders and website backgrounds.

## Categories

- Nature Videos
- Waterfall Videos
- City Lights Videos
- Building & Skyline Videos
- Abstract Background Videos

## Usage

Example:

```html
<video autoplay muted playsinline>
  <source src="https://syed-moinuddin2025.github.io/videos/citylights.mp4" type="video/mp4">
</video>
```
